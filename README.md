# Pretty Mangwadi - Portfolio Website

A modern, responsive portfolio website showcasing the professional journey of Pretty Mangwadi, a final-year Computer Science student at the University of the Witwatersrand.

## About

This portfolio website serves as a comprehensive showcase of Pretty's academic achievements, technical skills, leadership experience, and professional projects. The site reflects her passion for technology, community building, and creating innovative solutions that bridge the gap between technical excellence and real-world impact.

## Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Interactive Navigation**: Smooth scrolling navigation with active section highlighting
- **Dynamic CV Downloads**: Dual CV system offering both technical and social media-focused resumes
- **Project Showcase**: Detailed presentation of academic and personal projects
- **Skills Visualization**: Comprehensive display of technical and soft skills
- **Experience Timeline**: Professional and leadership experience documentation
- **Contact Integration**: EmailJS-powered contact form for direct communication
- **Gallery Section**: Visual portfolio of achievements and activities

## Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Grid and Flexbox
- **Icons**: Font Awesome 6.0
- **Typography**: Inter font family from Google Fonts
- **Email Service**: EmailJS for contact form functionality
- **Version Control**: Git with GitHub hosting
